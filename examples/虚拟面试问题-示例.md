# 前端开发实习 · 模拟面试问题

## 项目经历

### 1. 请详细描述你在项目中使用 React 或 Vue 实现的一个复杂状态管理场景，并说明为什么选择 Redux/Pinia 而不是其他方案？

- **难度**：中等
- **为什么问**：考察项目真实性、对状态管理的理解深度以及技术选型能力。
- **参考答案思路**：结合具体项目，阐述状态管理的需求（如跨组件共享、异步数据流），对比 Context/Props 的局限性，说明选择 Redux/Pinia 的原因及实际应用。

### 2. 你提到设计并实现了可复用组件库，请举一个组件的例子，说明你如何设计它的 API 和样式，使其具备良好的扩展性和可维护性？

- **难度**：中等
- **为什么问**：考察组件化设计能力和代码质量意识。
- **参考答案思路**：选择一个组件（如弹窗），说明 props 设计、插槽/children 使用、样式方案（如 CSS Modules 或 styled-components），以及如何通过文档和测试保证可维护性。

### 3. 在项目中使用 Vite 配置了路由懒加载和代码分割，请具体说明实现方式和效果，以及你如何验证性能提升？

- **难度**：困难
- **为什么问**：考察工程化实践和性能优化能力。
- **参考答案思路**：描述使用 React.lazy 或 Vue Router 的动态导入，通过 import() 分割代码块，并利用 Chrome DevTools 或构建产物分析验证首屏加载时间减少。
