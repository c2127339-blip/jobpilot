# 前端开发实习生（React / Vue）

> 说明：本文件是示例 JD，可根据你实际投递的岗位替换。

## 职位描述

- 参与公司 Web 产品的前端开发与维护，负责页面功能实现与交互优化
- 与 UI、后端工程师协作，完成产品需求落地
- 编写清晰、可维护的前端代码，参与代码评审

## 任职要求

- 熟悉 HTML、CSS、JavaScript，掌握 ES6+ 语法
- 了解 React 或 Vue 任一框架，理解组件化开发思想
- 了解 Git 基本使用，理解版本管理与团队协作流程
- 有实际项目经验者优先（校园项目、个人项目均可）
- 学习能力强，对前端技术有热情，具备良好的沟通与协作能力

## 加分项

- 了解 TypeScript
- 了解 HTTP 协议与浏览器工作原理
- 有使用前端构建工具（Vite / Webpack）的经验
